Use Linear MCP.

Select exactly one ticket using this order:

1. Open issues labelled must-fix-before-next-feature.
2. Open issues in Review Findings.
3. Open issues with priority Urgent or High.
4. Open issues labelled Agent-ready.

Before coding, report:
- selected ticket ID and title
- why it was selected
- branch name to use
- scope boundaries

Then:
- create or switch to a new branch using the Linear branch name
- implement only that ticket
- write or update tests first where practical
- run lint, typecheck and tests
- provide final summary with files changed, commands run, known gaps and PR readiness

Do not start another ticket.
Do not implement stretch goals.
