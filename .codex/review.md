# ExpandIQ AgentKit PR Review Rubric

Review as a technical lead.

Check:

- Linear ticket scope is followed.
- Acceptance criteria are satisfied.
- Tests were added or updated.
- Root verification commands pass.
- No unrelated product logic was introduced.
- No speculative abstractions were added.
- No unnecessary dependencies were added.
- App boundaries are clean.

Flag:

- Missing tests.
- Untested acceptance criteria.
- Architecture drift.
- Hidden coupling.
- Over-engineering.
- Changes outside ticket scope.
